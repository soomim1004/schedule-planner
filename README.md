# 개인 비서 캘린더

할 일의 마감일, 중요도, 난이도, 예상 소요 시간을 바탕으로 우선순위를 계산하고 자동으로 추천 일정을 만들어 주는 개인 일정 관리 웹앱입니다.

## 주요 기능

- 할 일 추가, 수정, 삭제, 완료 처리
- 카테고리 추가, 수정, 삭제
- 마감일, 중요도, 난이도, 예상 소요 시간 기반 우선순위 정렬
- 날짜별 작업 가능 시간 설정
- 기존 일정 등록으로 자동 배치 시 충돌 방지
- 추천 일정 목록 보기
- 추천 일정 캘린더 보기
- 완료된 항목 일괄 정리
- 브라우저 `localStorage`를 이용한 데이터 저장

## 사용 기술

- HTML
- CSS
- JavaScript

별도의 프레임워크나 빌드 도구 없이 동작하는 정적 웹앱입니다.

## 실행 방법
### URL
1. https://soomim1004.github.io/schedule-planner/ 를 URL 입력창에 입력한다


### 컴퓨터
1. 저장소를 내려받습니다.

```bash
git clone https://github.com/soomim1004/schedule-planner.git
cd schedule-planner
```

2. `index.html` 파일을 브라우저에서 엽니다.

Windows에서는 파일을 더블 클릭해도 실행할 수 있습니다.

## 사용 방법

1. 왼쪽 입력 영역에서 할 일 제목, 카테고리, 마감일, 예상 시간, 중요도, 난이도를 입력합니다.
2. 필요하면 날짜별 작업 가능 시간과 기존 일정을 추가합니다.
3. `자동 일정 짜기` 버튼을 눌러 추천 일정을 생성합니다.
4. 추천 일정은 목록 또는 캘린더 보기로 확인할 수 있습니다.
5. 완료한 할 일은 체크박스로 표시하고, 완료 항목 정리 버튼으로 삭제할 수 있습니다.

## 자동 일정 배치 기준

앱은 다음 요소를 함께 고려해 할 일을 정렬하고 배치합니다.

- 마감일까지 남은 날짜
- 중요도
- 난이도
- 예상 소요 시간
- 날짜별 작업 가능 시간
- 이미 등록된 기존 일정

기본 작업 가능 시간은 오전 9시부터 오후 9시까지이며, 하루 기본 집중 가능 시간은 6시간입니다. 날짜별 설정을 추가하면 해당 날짜에는 별도 기준이 적용됩니다.

## 데이터 저장 방식

입력한 할 일, 카테고리, 날짜별 설정, 기존 일정은 브라우저의 `localStorage`에 저장됩니다. 따라서 같은 브라우저에서는 새로고침 후에도 데이터가 유지됩니다.

브라우저 저장 데이터를 삭제하거나 다른 브라우저에서 접속하면 기존 데이터가 보이지 않을 수 있습니다.

## 배포

정적 파일만으로 동작하므로 GitHub Pages, Netlify, Vercel 같은 정적 호스팅 서비스에 바로 배포할 수 있습니다.

GitHub Pages를 사용할 경우 저장소에 파일을 올린 뒤 `Settings > Pages`에서 배포 브랜치를 선택하면 됩니다.
